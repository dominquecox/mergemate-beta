Read-only by design

MergeMate never merges, approves, comments on or changes anything in GitHub.

You choose the access

AI with consent

Nothing is sent to an AI model until you agree, and credentials are stripped from code first.

Leave anytime

A companion, not a replacement

Works alongside GitHub

GitHub is where code changes. MergeMate is where you decide what deserves your attention, then opens the pull request in GitHub when you're ready to act.

Built on Meta AI

MergeMate uses Meta's Muse Spark and Llama models to read pull requests and explain them in plain language.
