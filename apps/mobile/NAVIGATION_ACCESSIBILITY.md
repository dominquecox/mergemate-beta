# Navigation and switch accessibility

Web route transitions move focus to the visible screen heading with `tabindex=-1` and prevent-scroll, including Search/Back, tabs, account-modal Cancel and sign-in redirects. Outgoing focus is released before a screen hides. Hidden, inert, removed and unlaid-out headings are not focused. Focus follows the pathname, not background data or control updates. Native headings retain their accessible header roles. The shared header can wrap; stack animations respect live reduced-motion preferences on web and native.

Desktop navigation uses actual Expo links, including account settings. Flatten child styles before passing them through Expo's child slot; arrays/functions there can break desktop rendering. Hover and pressed colors remain the approved theme colors.

Every settings, browser-notification and repository-watch switch uses a52x44 interactive target around the compact40x20 visual track. Web switches are real buttons with switch role, checked state, label, visible keyboard focus and enforced aria-disabled state. They retain keyboard focus while a preference write is pending and reject changes while disabled. Native uses one accessible switch target around the native visual control, with its nested visual excluded from the accessibility tree and pointer handling. No extra native Tab stop or duplicate press handler is introduced.

## Local fixture smoke

Export the real app with `EXPO_NO_TELEMETRY=1 EXPO_PUBLIC_API_BASE_URL=https://api-dev.mergemate.dev npm run export:web -w @mergemate/mobile`, then run `node apps/mobile/scripts/check-navigation-focus.mjs`. The script starts a loopback server on an ephemeral port and mocks every external API transport. It uses installed Chrome and blocked service workers. At320/393/1440 it checks keyboard Search/Back, tab/sidebar links, modal Cancel, sign-in focus, no hidden-focus warning, enlarged heading layout, no horizontal overflow, real switch geometry, edge clicks, Enter/Space and single preference/watch writes. Screenshots are saved under `/private/tmp/mergemate-navigation-focus`. It neither deletes an account nor sends a real provider notification.

Unit tests cover visible/hidden/removed/no-layout heading focus, prevent-scroll and native/no-DOM safety. iOS/Android JavaScript exports verify packaging, not device acceptance. VoiceOver/TalkBack order, native interaction and OS text scaling still require actual signed devices; this receipt does not claim a complete WCAG certification or production acceptance. Existing consent, auth, suspension, mutation locks and optional-feature defaults remain unchanged.
